## Critical findings

### C-1 — No authentication on SSE REST API
**File:** `sse/src/restServer.js` — all routes  
**Detail:** `POST /api/scenario`, `GET /api/alerts`, `GET /api/sensors`, `GET /api/system-health` accept requests from any origin without JWT validation. An unauthenticated user can change the active scenario (e.g., trigger INTRUSION mode) or harvest all sensor alert data.  
**Fix:** Add JWT middleware to all routes except `GET /api/health`. Token should be validated against the same secret used by the dashboard.  
**Label:** `bug`, `critical`, `security`

### C-2 — `global.__wss` unsafe global assignment
**File:** `sse/src/index.js:53`  
**Detail:** `global.__wss = wsServer` assigns the WebSocket server instance to Node.js global state. This makes the service untestable (tests can't reset state), creates hidden coupling between modules, and would cause issues in any multi-process or clustering setup.  
**Fix:** Pass `wsServer` as a parameter to any function that needs it. Remove the global assignment entirely.  
**Label:** `bug`, `critical`

## Major findings (backend SSE)

### M-8 — SSE is plain JavaScript, not TypeScript
All `sse/src/` files are `.js`. CLAUDE.md stack requires TypeScript for backend services.  
**Label:** `bug`, `major`, `backend`

### M-9 — Zod validation absent on all SSE routes
Only `POST /api/scenario` has any validation (raw Fastify JSON schema). Other routes have none.  
**Label:** `bug`, `major`, `backend`

### M-10 — Default exports in all SSE generator classes
`SeismicGenerator`, `AcousticGenerator`, `OpticalGenerator`, `RadarGenerator`, `MagneticGenerator`, `ChemicalGenerator`, `FibreGenerator`, `AimlGenerator`, `scenarioManager`, `sensorPayloadSchema` all use `export default`.  
**Label:** `bug`, `major`, `conventions`

### M-11 — 14+ `console.log` calls in SSE production code
Across `wsServer.js`, `index.js`, `restServer.js`, `correlator.js`, `scenarioManager.js`, `generators/base.js`, `generators/aiml.js`. No structured logger installed.  
**Label:** `bug`, `major`, `backend`
