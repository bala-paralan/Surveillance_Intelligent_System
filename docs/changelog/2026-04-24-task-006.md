### Key design decisions

- **Stub mode**: if `ultralytics` is not installed, `YoloDetector` automatically falls back to a deterministic stub so all tests pass in CI without GPU or model files.
- **Non-fatal Redis**: detection events are published to Redis pub/sub (`detections:{camera_id}`) but any connection failure is logged as a warning and never raises to the caller.
- **Motion detection**: uses OpenCV frame differencing with morphological opening to filter sensor noise; returns a boolean for downstream consumers.
- **Intrusion detection**: normalises bbox centres to `[0, 1]` space and tests membership in each zone polygon via ray casting; only detections with `confidence >= 0.6` are evaluated.
- **Zone registry**: per-camera zone lists are held in a module-level dict and can be set via `POST /zones` or overridden per-request via the optional `zones` form field on `POST /detect`.
