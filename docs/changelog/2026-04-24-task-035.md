# TASK-035 — Seismic Sensor Ingestion + Pattern Classification (2026-04-24)

## What was built

- `src/analytics/detectors/seismic/driver.py` — abstract `SeismicDriver` interface
- `src/analytics/detectors/seismic/driver_reference.py` — `ReferenceSeismicDriver` with synthetic waveform generation (NORMAL/FOOTSTEP/VEHICLE/TUNNEL/ANIMAL scenarios)
- `src/analytics/detectors/seismic/classifier.py` — `SeismicClassifier` FFT-based rule classifier returning `SeismicEvent` (type, confidence, direction_deg, distance_m, pattern_window_ms)
- `src/analytics/detectors/seismic/ingestion_worker.py` — `SeismicIngestionWorker` async loop
- `src/analytics/detectors/seismic/publisher.py` — Redis pub/sub on `sensor:event:seismic`; non-fatal on Redis unavailability
- `src/analytics/api/routes.py` extended: `GET /analytics/seismic/health`, `POST /analytics/seismic/classify`
- `src/backend/prisma/schema.prisma` — `SensorEventType` enum + `SensorEvent` model added

## Security
- Raw waveform data never logged at info level; only event type + sensor_id
