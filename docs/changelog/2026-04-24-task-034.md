## Behaviour

- Users with ENGINEER or ADMIN role see a mode toggle in the nav dropdown.
- When in `engineering` mode, an "Engineering" nav link appears linking to `/engineering`.
- Switching mode persists via `PATCH /users/me/preferences` and updates the store immediately.
- `EngineeringRoute` renders a 403 page for anyone without ENGINEER/ADMIN role.
