# TASK-033 — Multi-AOI Quadview Panel

**Date:** 2026-04-24  
**Agent:** Frontend

## Summary
Implemented the multi-AOI quadview layout system, allowing operators to monitor 1, 2, or 4 AOIs simultaneously in configurable split-screen layouts.

## Files created
- `src/frontend/src/store/layoutStore.ts` — Zustand persisted store (`localStorage` key `sis-layout`); state: `layout: '1'|'2h'|'2v'|'4'`, `paneAois: [string|null, ...]`; actions: `setLayout`, `setPaneAoi`
- `src/frontend/src/components/map/AoiSelector.tsx` — Dropdown listing AOIs from `aoiStore`; calls `layoutStore.setPaneAoi` on change
- `src/frontend/src/components/map/AoiPane.tsx` — Per-pane container; reads `aoiId` from layoutStore, shows AoiSelector header, renders AoiMap + AlertTicker, displays sensor count, empty state for unselected pane
- `src/frontend/src/components/layout/QuadviewLayout.tsx` — CSS-grid container that renders 1/2/4 `<AoiPane>` components based on current layout
- `src/frontend/src/components/layout/LayoutSwitcher.tsx` — Toolbar with "1×1", "2H", "2V", "2×2" buttons; active layout highlighted in indigo

## Files modified
- `src/frontend/src/pages/OperatorDashboard.tsx` — Complete rewrite: full-height layout with `<LayoutSwitcher>` toolbar + `<QuadviewLayout>` main content, replacing the old stats-grid + AlertFeed layout

## Layout modes
| Code | Grid | Visible panes |
|------|------|---------------|
| `1`  | 1×1  | Pane 0 only   |
| `2h` | 2 cols | Panes 0, 1  |
| `2v` | 2 rows | Panes 0, 1  |
| `4`  | 2×2  | Panes 0–3     |
