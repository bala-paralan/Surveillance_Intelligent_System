# 2026-04-24 — TASK-041: BOP/Site Hierarchy Model + TASK-034: ENGINEER Role

## Summary

Implemented the BOP (Battery Operations Platform) site hierarchy data model, GIS sync service,
BOP REST routes, and the ENGINEER role with UI mode preferences.

## Schema changes (`src/backend/prisma/schema.prisma`)

- Extended `Role` enum: added `ENGINEER`
- Added `SensorType` enum: `SEISMIC | ACOUSTIC | THERMAL | LIDAR | PAN | CAMERA`
- Added `SensorHealth` enum: `HEALTHY | DEGRADED | OFFLINE | UNKNOWN`
- Extended `User` model: `bopScope String[]`, `zoneScope String[]`, `uiMode String?`
- New `Bop` model: id, code (unique), name, zones[], assets[], timestamps
- New `BopZone` model: id, bopId (FK→Bop), code, name, parentZoneId (self-ref), sensors[],
  unique constraint on (bopId, code)
- New `Asset` model: id, bopId (FK→Bop), zoneId (nullable FK→BopZone), kind, lat, lon, metadata (Json)
- New `GisSyncLog` model: tracks each sync run (status, counts, error messages)
- New `Sensor` model (TASK-032 prep): type, lat/lon, bopZoneId, health, encryptedSecrets
- New `Aoi` model (TASK-031 prep): GeoJSON polygon, bopZoneId, createdById (FK→User), soft-delete via deletedAt

## New service (`src/backend/src/services/gis-sync-service.ts`)

- `GisSource` interface with `fetchAll(): Promise<GisData>`
- `GeoPackageMockSource` — fixture data with 5 BOPs (ALPHA–EPSILON), 4 zones each, 20 assets each
- `runGisSync(source)` — creates a GisSyncLog, upserts BOPs/zones/assets in a Prisma transaction,
  updates log with counters and final status; never logs lat/lon at info level

## Auth middleware (`src/backend/src/middleware/auth.ts`)

- Extended `JwtPayload` to include `roles: Role[]` and `scope: { bop_ids, zone_ids }`
- Added backwards-compat shim in `verifyJwt` for tokens without `roles`/`scope`
- New `requireScope(bopId)` middleware factory; ADMINs always pass, others need bopId in scope

## Auth service (`src/backend/src/services/auth-service.ts`)

- `issueAccessToken` now embeds `roles: [role]` and `scope: { bop_ids, zone_ids }` from `user.bopScope`/`user.zoneScope`

## New routes

### `src/backend/src/routes/bop.ts`
- `GET  /bop`           — list all BOPs (VIEWER+)
- `GET  /bop/:id`       — single BOP with zones (VIEWER+, BOP-scope-checked)
- `GET  /bop/:id/zones` — zone list for BOP (VIEWER+)
- `POST /bop/sync`      — trigger GIS sync fire-and-forget (ADMIN only, returns 202)
- `GET  /bop/sync/logs` — last 20 sync logs (ADMIN | ENGINEER)

### `src/backend/src/routes/preferences.ts`
- `PATCH /users/me/preferences` — update `uiMode` ('operator' | 'engineering')
  Only ENGINEER or ADMIN may set `uiMode` to `'engineering'`; returns updated user without secrets

## Server registration (`src/backend/src/index.ts`)

- Registered `bopRoutes` and `preferencesRoutes`
