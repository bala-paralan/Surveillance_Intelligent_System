## Summary

Implements the full Sensor & Asset Catalogue feature, including spatial point-in-polygon query over AOI geometries stored as GeoJSON text (no PostGIS dependency), REST endpoints for sensor CRUD + health updates, and a live-refreshing frontend catalogue panel embedded in the AOI page.

---

## Backend changes

### `src/backend/src/services/catalogue-service.ts` (new)
- Exports `CatalogueItem`, `SensorPublic` types and `listForAoi(aoiId)` async function.
- Loads AOI from DB, parses `geometryJson`, runs **ray-casting point-in-polygon** test (`pointInPolygon`) for every sensor and asset.
- Cameras matched approximately by `siteId == aoi.bopZoneId` (v1, no lat/lon on Camera model).
- Returns merged, sorted `CatalogueItem[]` — sorted by kind (sensor < camera < asset) then type.
- Logs only `aoiId` + item counts — never logs lat/lon.
- Exports `toSensorPublic()` helper that strips `encryptedSecrets`.

### `src/backend/src/routes/catalogue.ts` (new)
Five routes registered under a single Fastify plugin:

| Method | Path | Auth |
|--------|------|------|
| GET | `/aoi/:aoiId/catalogue` | VIEWER+ |
| GET | `/sensors` | VIEWER+ |
| POST | `/sensors` | ADMIN \| ENGINEER |
| GET | `/sensors/:id` | VIEWER+ |
| PATCH | `/sensors/:id/health` | ADMIN \| ENGINEER |

- All inputs validated via Zod schemas.
- `SensorPublic` never exposes `encryptedSecrets`.
- Pagination on `GET /sensors` via `page` + `pageSize` query params (default 1/50, max 200).

### `src/backend/src/services/seed-sensors.ts` (new)
- Exports `seedSensors(): Promise<void>`.
- Inserts 30 fixture sensors across zone codes `ALPHA-1`, `ALPHA-2`, `BETA-1`.
- Sensor types cycle: SEISMIC, ACOUSTIC, THERMAL, LIDAR.
- Random lat/lon within 0.1° square of `[88.17, 21.96]`.
- Skips gracefully when zones don't exist; catches all errors non-fatally.

### `src/backend/src/index.ts` (updated)
- Imports and registers `catalogueRoutes` after `aoiRoutes`.

## Frontend changes

### `src/frontend/src/api/catalogue.ts` (new)
- Exports `CatalogueItem` and `SensorPublic` interfaces.
- `listCatalogue(aoiId)` — calls `GET /aoi/:aoiId/catalogue`.
- `listSensors(bopZoneId?)` — calls `GET /sensors` with optional filter.

### `src/frontend/src/components/catalogue/CataloguePanel.tsx` (new)
- Accepts `aoiId: string` prop.
- Uses `useQuery` from `@tanstack/react-query` with `staleTime: 30_000` and `refetchInterval: 30_000`.
- Loading spinner while fetching; error state with message.
- Groups items by `type` key, renders each group with header + item rows.
- Each row: health indicator dot (green/yellow/red/gray), type badge coloured by kind, truncated ID, last-heartbeat time-ago.
- "No sensors found in this AOI" empty state with icon.

### `src/frontend/src/pages/AoiPage.tsx` (updated)
- Added `CataloguePanel` import.
- Replaced `<main>` wrapper with a `flex-col` container.
- Added a fixed-height (h-56) bottom panel below the map.
- When `activeAoiId !== null` renders `<CataloguePanel aoiId={activeAoiId} />`.
- When no AOI selected renders "Select an AOI to see its sensor catalogue" placeholder.

## Security notes
- `encryptedSecrets` is never returned in any API response (stripped in `toSensorPublic`).
- Lat/lon values are never logged at info level.
- All sensor write endpoints require ADMIN or ENGINEER role.
