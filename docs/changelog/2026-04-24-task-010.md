# TASK-010 — GitHub Actions CI/CD Pipeline

**Date:** 2026-04-24
**Agent:** DevOps

## What was built

Two GitHub Actions workflows for automated testing and deployment.

### Files created

| File | Purpose |
|---|---|
| `.github/workflows/ci.yml` | Runs on every push to `main` / `claude/**` and all PRs targeting `main` |
| `.github/workflows/deploy.yml` | Triggers on push to `main`; gates on all three CI checks |

### CI workflow jobs

| Job | Runner | Steps |
|---|---|---|
| `backend-check` | ubuntu-latest | `npm ci` → `typecheck` → `test:backend` (with postgres service) |
| `analytics-check` | ubuntu-latest | `pip install` → `pytest --tb=short -q` |
| `frontend-check` | ubuntu-latest | `npm ci` → `typecheck` → `npm test -- --run` |

### Deploy workflow

- Calls CI jobs first via `needs`
- Each deploy step is a placeholder `curl` hook (activate by setting `RENDER_DEPLOY_HOOK_*` secrets)
- Three separate deploy jobs: backend, analytics, frontend

### Security
- Secrets referenced via `${{ secrets.* }}` — never hardcoded
- Test env vars limited to safe placeholder values with no real credentials
