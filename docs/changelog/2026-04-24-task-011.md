### Grafana dashboard panels

1. HTTP Request Rate (backend) — `rate(http_requests_total[1m])` by route+method
2. HTTP p95 Latency (backend) — `histogram_quantile(0.95, ...)` by route
3. Detection Count by Type (analytics) — `increase(detection_requests_total[5m])` by detector_type
4. Active Sensors Count — stat panel

### Security note
`GET /metrics` endpoints are on internal ports (9091 / 9092) not exposed publicly. Both are tagged `skipAuth: true` but are unreachable from the internet in the Kubernetes production deployment.
