# TASK-040 — Human-Readable Alerts on Live Map

**Date:** 2026-04-24  
**Agent:** Frontend

## Summary
Implemented the AlertTicker overlay and AlertDetailModal for displaying human-readable, actionable alerts directly on the live AOI map view.

## Files created
- `src/frontend/src/components/alerts/NarrativeTemplate.tsx` — Pure `narrativeFromAlert(alert)` function + `<NarrativeTemplate>` component; templates for INTRUSION, MOTION, PERSON, VEHICLE, SEISMIC, ACOUSTIC, SYSTEM
- `src/frontend/src/components/alerts/AlertTicker.tsx` — Polls `/alerts?aoiId=&acknowledged=false&limit=5` every 10 s; renders up to 5 cards anchored to top-right of map; CRITICAL cards have pulsing border; Ack button for OPERATOR/ADMIN
- `src/frontend/src/components/alerts/AlertDetailModal.tsx` — HTML `<dialog>` modal with full alert detail (narrative, severity, timestamps, zone info), Acknowledge and Resolve buttons (OPERATOR/ADMIN only), backdrop-click to dismiss

## Files modified
- `src/frontend/src/pages/AoiPage.tsx` — Added `<AlertTicker aoiId={activeAoiId} />` inside the relative-positioned map container
- `src/frontend/src/index.css` — `@keyframes critical-pulse` for animated red border on CRITICAL cards (added as part of TASK-038 CSS block)

## Behaviour
- Each card shows severity badge, natural-language message (via NarrativeTemplate), time-ago, and optional Ack button
- CRITICAL alerts show a bell icon (&#128276;) and the `alert-critical-pulse` CSS animation
- Clicking any card opens the AlertDetailModal for full details and action buttons
- No audio in v1 due to browser autoplay restrictions
